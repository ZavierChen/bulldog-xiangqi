# 斗牛犬 · Bulldog Xiangqi

<img src="assets/bulldog.png" width="128" alt="戴眼镜、读书和下象棋的灰色卡通斗牛犬">

Windows 本地象棋助手，使用 [Pikafish](https://github.com/official-pikafish/Pikafish) 搜索与评估。项目重点是把视觉识别、合法局面追踪、后台多分支预判和搜索时间调度连起来，减少等待期间的重复工作。界面分为 **连接对局、沙盒摆棋、设置与诊断**。

## 算法与调度

皮卡鱼负责底层搜索和 NNUE 评估；本项目没有另造一个棋力引擎，主要实现以下衔接策略：

| 环节 | 方法 | 作用 |
| --- | --- | --- |
| 棋盘识别 | 多尺度边框定位、棋子圆形检测、90 格批量 CNN 分类 | 将图像转为逻辑棋盘；可选 DirectML 加速识别 |
| 局面同步 | 用引擎合法走法匹配新旧棋盘 | 通过已确认的一步推进历史与走棋方，减少重复回合判断 |
| 对方思考期间 | MultiPV 同时覆盖 2–5 个候选分支 | 避免只押一条路线；只发布同一深度的完整候选集合 |
| 预判复用 | 历史、局面与实际应手严格匹配；逐分支检查回复稳定性 | 稳定命中可直接复用，未命中则重新搜索 |
| 失焦恢复 | 暂停搜索但保留分支、主变化、已算着法和引擎进程 | 同局面不重算，已搜索路径命中后保留历史继续走 |
| 搜索状态复用 | 将后台引擎进程切换为前台，保留置换表 | 继续利用已搜索节点，不在每步重建引擎或调整线程 |
| 资源预算 | 预判在稳定窗口后暂停，达到上限也停止；连续劣势逐步加时 | 控制无效后台计算，开局保持基础预算 |
| 防循环 | 对候选走法检查历史重复和长将状态 | 拦截重复循环；属于保守策略，不是完整长捉裁判 |
| 沙盒建议 | 一次限时 MultiPV=3 搜索，按评分排列、编号箭头显示 | 比较同一手的三种选择；编辑局面立即使旧结果失效 |

具体判据、默认参数及局限见 [算法说明](docs/ALGORITHMS.md)。这里描述的是实现机制，不将小样本测速或评分稳定性等同于棋力提升证明。

## 沙盒

- 自己摆棋：选择红黑棋子后点格子放置，拖动或两次点击移动，右键删除；支持清空、撤销、翻转、FEN 导入/复制。
- 选择红/黑走棋，然后点“电脑提示”。一次限时 MultiPV 搜索给出**同一手的三个候选走法**，按当前方评分排序，画出编号和彩色箭头。
- 点击建议卡突出显示箭头；“走选中的这一步”只改变本地沙盒。编辑局面会取消并清除旧建议。
- 提示只在点击时计算。连接正在运行时，先停止连接再分析沙盒，避免同时争用计算资源。

## 连接对局

识别已支持皮肤的棋盘、同步合法走法历史并调用引擎。无头像保底仅有“我方先手 / 对方先手”，下方始终视为本方。仅识别成功且窗口、局面、回合复核通过后才落子。

支持后台多分支预判、稳定后暂停、持续劣势时动态加时、自动恢复连接和已验证界面的广告/升级/积分加速/续局处理。“积分加速”同时核对卡片标题与右上角红叉，关闭后回到续局流程；不点击看视频获取积分按钮。新的界面和广告样式可能需要重新适配。防长将/长捉采用保守防重复局面策略，可能放弃本可判和的重复；它不是完整的平台棋规裁判。

显示的红黑评分、胜/和/负仅复用既有搜索输出。概率是引擎模型估计；没有当前结果时显示“暂无”，不会为显示而追加搜索。

## 手动识别与新皮肤

1. 点击 **手动识别 · 选两点**，选择棋局所在窗口。可以选择其他软件的可见窗口。
2. 在窗口截图中点击棋盘**左上、右下的交叉点**，以棋子中心为准，不选棋盘外框。紫色 9×10 网格对齐后点确定。
3. 点击开始连接。默认本方为下方、我方先走；已有合法历史会优先保留。如果试走未生效，保留计算等待实际变化；对方走完后按合法走法纠正回合。

角点相对所选窗口的内容区域保存，平移窗口时重新换算屏幕坐标，也可适应左右黑边变化。窗口内布局变化或网格未对齐时需重新选点。

对常见圆形棋子，新皮肤在**标准开局或红方只走过一步**时可按固定位置与合法开局走法匹配，快速学习外观。确认过的外观特征压缩保存在本机皮肤库，断线、续局和重启不会遗忘；中局可直接加载匹配的皮肤，并用现有棋子分类和中文 OCR 补充。开局学习只是初始化捷径，复杂艺术字体仍可能需要手动校正。

外观匹配和中文 OCR 使用本机 ONNX Runtime / DirectML；CPU 执行定位、裁切与合法性核对。中文模型首次使用前运行 `install_dependencies.bat`，已有环境也可运行 `python tools/install_ocr.py` 单独安装。模型约 11 MB，按固定版本和 SHA256 下载。皮肤库位于 `connector/bridge/local_data/skins/`，仅存特征与棋子标签，不保存整屏截图，不上传 GitHub。

识别受特效干扰时保留最后确认的棋盘、走棋方和搜索结果。仍无法恢复时，点 **手动校正并续接**：连接暂停，在沙盒中移动、补放或删除棋子，选当前红/黑走棋，再点 **确认棋盘并续接**。程序核对位置与稳定性，学习确认后的外观，再继续连接；若局面未变或命中已搜索路径，会保留原有计算。暂时遮挡棋子主体时等待特效消失，不将不确定的画面覆盖到已确认棋盘上。

失焦只暂停后台工作，保留本次运行的搜索分支和置换表。恢复后局面不变就复用已算着法，落在已搜索路径上则沿用该变化；新一局或不能确认的变化会重新同步。退出程序后不保存引擎置换表。

## 使用

需要 Windows 10/11、原生 64 位 **CPython 3.12（含 Tk）**。

1. 安装 Python 后运行 `install_dependencies.bat`。它创建 `.venv`，安装固定版本依赖，并从官方源下载、校验引擎。
2. 双击 `启动斗牛犬.bat`。现有本地完整环境也可继续使用。
3. 连接模式只打开一个受支持的象棋窗口；沙盒不需要外部应用。

命令行安装：

```powershell
py -3.12 tools/setup.py
# 仅 CPU 识别：
py -3.12 tools/setup.py --cpu-only
```

GPU 只加速棋子识别；Pikafish 搜索使用 CPU。基础秒数为本方搜索预算，动态加时尚未接入平台剩余时钟。

## 源码与本机数据

仓库包含源码、必要识别模板、来自开源项目的 ONNX 棋子模型、图标和测试。个人设置、棋谱、日志、原始截图、测速数据、开发备份及归档仅保存在本地，不上传到仓库或 Release。已有本地开局缓存也不公开；缺少缓存时正常使用引擎。引擎二进制、NNUE、Python 运行库通过安装脚本取得。

引擎固定为 `Pikafish-2026-09-06`；下载压缩包及解出的 exe/NNUE 都验证 SHA256。必要时可设置 `PIKAFISH_ENGINE` 指向其他兼容引擎。

```powershell
python -m unittest discover -s tests -v
```
